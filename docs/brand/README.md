# هوية إرثي

الملف `master.jpg` هو المرجع الذي أرفقه المالك، محفوظ بالبايتات الأصلية. ملفات WebP قصّ دائري من المرجع بمقاسات مختلفة، مع شفافية حول الختم. الكتاب في `book.svg` رسم SVG أصلي مبسّط مستوحى من الكتاب المفتوح في الختم.

| الملف داخل public/brand | الاستخدام |
| --- | --- |
| seal.webp | الختم الكامل بدقة 1536 × 1536 |
| seal-dark.webp | الصفحة الرئيسية على الخلفية الداكنة |
| seal-mobile.webp | الختم بحجم أخف للهاتف |
| seal-header.webp | رأس الموقع |
| seal-footer.webp | تذييل الموقع |
| book.svg وbook-32.png | أيقونة المتصفح |
| book-192.png وbook-512.png | أيقونات بيان تطبيق الويب |
| social.jpg | مشاركة Open Graph بمقاس 1200 × 630 |

لوحة الواجهة مستوحاة من عينات مناطق الخلفية والحواف في الختم، مع رفع تباين لون النص. الألوان الرئيسية هي الأسود الدافئ `#120d0b` والبني الداكن `#19110e` والذهبي الفاتح `#efc486` والذهبي المعدني `#cb914d` والبرونزي `#906237` والعاجي `#fcf2e5`.

## النص القرآني

قورنت العبارتان الظاهرتان في الختم بنص [الرحمن 55:26](https://quran.com/55/26) و[الأعلى 87:17](https://quran.com/87/17). تتطابق الكلمات والموضعان. تفاصيل الضبط في الختم جزء من الرسم، وأُبقيت داخل الصورة المعتمدة. لم يُنقل نقش صفحات الكتاب المصوّر أو أي نص قرآني إلى عناصر الواجهة.

## تراخيص الطرف الثالث

- أيقونات الواجهة من [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) بترخيص MIT. يوجد إشعار الترخيص في `fluent-license.txt`.
- رمزا Android وGitHub من [Simple Icons](https://github.com/simple-icons/simple-icons) بترخيص CC0. يظل استخدام الشعارين خاضعًا لإرشادات علامتيهما التجاريتين.
- خطا Noto Sans Arabic وNoto Kufi Arabic بترخيص SIL Open Font License 1.1. راجع إشعارات الخطوط المرفقة.
- تُستخدم أصول ختم إرثي بوصفها هوية المبادرة. ترخيص الكود في جذر المستودع.
